# آوین؛ داشبورد مالی فارسی (Glassmorphism)

پروتوتایپ داشبورد مالی راست‌به‌چپ با طراحی شیشه‌ای، نمودارهای SVG انیمیشنی، حالت تیره/روشن و کاملاً ریسپانسیو. فقط HTML/CSS/JavaScript خالص، بدون فریم‌ورک و بدون مرحلهٔ build.

## ویژگی‌ها
- داشبورد: KPI، نمودار درآمد/هزینه (۷ روز، ۳۰ روز، ۱۲ ماه)، سهم هزینه‌ها، تراکنش‌های اخیر، اهداف پس‌انداز
- صفحات: تراکنش‌ها (فیلتر، مرتب‌سازی، صفحه‌بندی)، کارت‌ها (افزودن/حذف، سقف ۶ کارت)، بودجه، گزارش‌ها، تنظیمات
- چندکاربره: حساب نمونه (فقط‌خواندنی) و حساب‌های واقعی با داده‌ی خالی
- ثبت دستی تراکنش با تاریخ شمسی و ورود صورت‌حساب CSV/Excel (تشخیص خودکار ستون‌ها، حذف تکراری‌ها)
- مرکز اعلان‌ها و فهرست دستگاه‌های واردشده (دستگاه از userAgent، شهر تقریبی از IP)
- حالت سبک خودکار برای دستگاه‌های ضعیف (`?lite=1` اجباری، `?lite=0` غیرفعال)
- دسترس‌پذیری: ناوبری با کیبورد، برچسب‌های ARIA، احترام به `prefers-reduced-motion`

## ساختار پروژه
```
index.html      ساختار صفحه (HTML)
css/style.css   استایل‌ها: توکن‌های رنگ، حالت تیره/روشن، افکت شیشه‌ای، ریسپانسیو
js/app.js       منطق برنامه: نمودارها، مسیریابی، داده‌ها، ذخیره‌سازی، ورود صورت‌حساب
vercel.json     تنظیمات هدر برای Vercel
```

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید، یا:

```bash
npx serve .
```

## انتشار
- **GitHub Pages:** مخزن را بسازید، فایل‌ها را push کنید، در Settings ← Pages شاخهٔ `main` و پوشهٔ root را انتخاب کنید.
- **Vercel:** مخزن را Import کنید؛ Framework را روی «Other» بگذارید و تنظیمات build را خالی رها کنید.

## ذخیره‌سازی و محدودیت‌ها
- داده‌های حساب‌های واقعی فقط در `localStorage` همان مرورگر ذخیره می‌شود و بین دستگاه‌ها همگام نیست. کاربر نمونه چیزی ذخیره نمی‌کند.
- ورود/ورود دومرحله‌ای واقعی وجود ندارد (کلید «ورود دومرحله‌ای» نمایشی است). این‌ها به سرور نیاز دارند.
- خواندن فایل Excel کتابخانهٔ SheetJS را هنگام نیاز از cdnjs بارگذاری می‌کند؛ CSV بدون اینترنت هم کار می‌کند.
- شهر دستگاه از سرویس ipapi.co گرفته می‌شود و در صورت مسدود بودن خالی می‌ماند.
- فونت: Vazirmatn از Google Fonts؛ اگر «ایران‌یکان» روی دستگاه نصب باشد استفاده می‌شود.
